# Third-party geometry

Preset geometry is based on Gridfinity by Zack Freedman, the Gridfinity Rebuilt
implementation by Kenneth Hodson, and its implementation of Gridfinity Refined
by grizzie17. The native Python port implements the mating profile, bottom
magnet/screw pockets, crush ribs, and `refined_hole()` side pockets.

Source revision: [910e22d8607fd7f5f51ad5e5cbc5287a76810bfd](https://github.com/kennetek/gridfinity-rebuilt-openscad/tree/910e22d8607fd7f5f51ad5e5cbc5287a76810bfd)

Source files: `src/core/standard.scad` and `src/core/gridfinity-rebuilt-holes.scad`.
